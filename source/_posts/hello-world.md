深夜写下的第一行字，往往最不像样。
但总要有个开始——像在林子里点一盏灯，先是微弱的一豆，然后周围的轮廓慢慢显出来。

## 为什么写博客

写字是件慢事。它逼着人把含糊的念头拆开、摊平，再按顺序摆好。
很多时候，写着写着才发现：原来我并不知道自己在想什么。

所以这里更像一份**公开的草稿本**，而不是一本正经的作品集。

## 会放些什么

| 类型 | 说明 |
| --- | --- |
| 技术笔记 | 代码、工具、踩过的坑 |
| 读书与杂感 | 从诗到程序，都是理解世界的方式 |
| 日常碎片 | 风、雨、月亮，和一些小事 |

## 一句题记

> 最终，森林会记住一切。

愿此处的文字，也能被时间温柔地记住。

```python
def greet(name: str) -> str:
    return f"你好，{name}。"

print(greet("世界"))
